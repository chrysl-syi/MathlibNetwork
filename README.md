# Mathlib Network Visualization
MathlibNetwork is an interactive visualization tool designed for the Mathlib library inspired by [MathlibExplore](https://github.com/Crispher/MathlibExplorer.git)

The visualization of this project is based on static HTML files generated by [plotly](https://plotly.com/python/).

## Start
I've generated a static visualization file in Visualization.html

To run the project， get the DataSet **Mathlib** from [mathlib4](https://github.com/leanprover-community/mathlib4).
Change the code in main.py
```
pathStr = "YourPath\Mathlib"
```
